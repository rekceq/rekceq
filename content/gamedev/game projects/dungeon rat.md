Dungeon Rat is a project I started to stream on YouTube and start a devlog series. The main idea is to develop a base template for a classic roguelike video game abiding by the [Berlin Interpretation](https://roguebasin.com/index.php?title=Berlin_Interpretation) (pretentious ain't I?). It was a way to force me to commit more with a project 'cause I always have problems finishing them. I reduced scope and did all the other obvious stuff everyone knows but tend to ignore.
